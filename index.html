Activar o desactivar la pantalla táctil en 4 pasos

Hace falta ser administrador del equipo. Sirve para volver a activar el táctil tras una actualización o para apagarlo un rato, por ejemplo para limpiar la pantalla o usar solo ratón y teclado.

  1. Pulsa Windows + X y abre el Administrador de dispositivos (o pulsa Windows + R, escribe devmgmt.msc y Enter).
  2. Despliega Dispositivos de interfaz humana.
  3. Busca Pantalla táctil compatible con HID. El nombre puede variar un poco, pero suele llevar "HID" y "touch".
  4. Clic derecho y elige Habilitar dispositivo para activarla o Deshabilitar dispositivo para apagarla.

Prueba tocando la pantalla. Si no ves el cambio, reinicia el equipo. Si la desactivas, guarda antes tu trabajo.

Si no te aparece o no funciona

  • Clic derecho en la entrada, Actualizar controlador, y busca automáticamente.
  • Si falló tras una actualización: Propiedades, Controlador, Revertir controlador.
  • Si no hay entrada: reinicia el PC y revisa Windows Update.
  • Instala el controlador táctil de la web del fabricante de tu modelo.
  • Para ajustar la respuesta, busca en Windows "Calibrar la pantalla para entrada táctil o con lápiz".
  • Con monitor externo, comprueba que el táctil no esté desactivado en su menú.

Si hay daño físico o humedad, puede hacer falta una reparación técnica.

Preguntas frecuentes sobre la pantalla táctil en Windows 10

¿Cómo activo la pantalla táctil en Windows 10?

Abre el Administrador de dispositivos, entra en Dispositivos de interfaz humana, haz clic derecho en Pantalla táctil compatible con HID y elige Habilitar dispositivo. Si no responde al momento, reinicia el equipo.

¿Cómo desactivo la pantalla táctil en Windows 10?

Es el mismo camino: clic derecho en Pantalla táctil compatible con HID y Deshabilitar dispositivo. Es útil para limpiar la pantalla o usar solo ratón y teclado.

¿Por qué no me aparece la pantalla táctil en el Administrador de dispositivos?

Puede que el equipo no tenga pantalla táctil, que Windows no reconozca el hardware o que falte el controlador. Reinicia, busca actualizaciones de Windows e instala el controlador del fabricante de tu modelo.

Mi pantalla táctil dejó de funcionar tras una actualización, ¿qué hago?

En la misma entrada del Administrador de dispositivos prueba Propiedades, Controlador y Revertir controlador. Si no está disponible, usa Actualizar controlador.

¿Mi PC no tiene pantalla táctil, puedo tenerla?

Si el equipo no tiene pantalla táctil de serie, la forma sencilla es conectar un monitor táctil por HDMI o USB-C. Existen modelos portátiles.
